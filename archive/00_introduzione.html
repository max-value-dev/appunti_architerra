Livelli di astrazione e macchine

Un calcolatore fisico è composto da transistor e circuiti complessi ed è impraticabile da programmare direttamente a livello hardware. Per questo motivo, l'architettura dei sistemi è strutturata in 5 livelli di astrazione cumulativi.

Livello 4 — Linguaggio Orientato al Problema C / Java / Python

Linguaggi ad alto livello con costrutti condizionali strutturati, tipizzazione forte, polimorfismo e astrazioni avanzate. Vengono tradotti (compilati o interpretati) in assembly o bytecode.

Livello 3 — Linguaggio Assembly Assemblatore

Rappresentazione simbolica leggibile delle istruzioni macchina (es. add, lw, sw). Tradotta in binario puro direttamente dall'Assemblatore.

Livello 2 — Macchina del Sistema Operativo Interpretazione Parziale

Introduce nuove astrazioni (File System, Memoria Virtuale, Thread e processi concorrenti). Gestisce I/O complessi che differiscono tra macchine diverse (es: Hard Disk, USB Key) uniformando l'interfaccia.

Livello 1 — Instruction Set Architecture (ISA) RISC-V / ARM / x86

Il contratto tra l'hardware e il software. È l'insieme di istruzioni macchina (bit) eseguite direttamente dai circuiti logici (o microprogramma) della CPU.

Livello 0 — Logica Digitale Esecuzione Hardware

Porte logiche elementari costruite tramite transistor, collegate per formare la ALU (Arithmetic Logic Unit), registri fisici e il Data Path interno.

Architettura vs Organizzazione

Architettura dei Calcolatori

L'insieme dei tipi di dati, istruzioni, registri e funzionalità della macchina visibili al programmatore dell'assembly. Rappresenta il modello concettuale e il set di regole operative (ISA).

Organizzazione dei Calcolatori

La struttura fisica e le relazioni funzionali di dettaglio (bus, cache, circuiteria ALU) che implementano una data architettura. Non è visibile al programmatore software ed è specifica del costruttore.

Misurare le prestazioni CPU

Il tempo di calcolo effettivo dipende dall'efficienza combinata dell'architettura software, dal set di istruzioni ISA e dalla frequenza del clock hardware.

Tempo di esecuzione

Il tempo totale necessario a completare un singolo task (tempo di CPU utente + tempo di CPU di sistema). Ridurre questo tempo è l'obiettivo delle ottimizzazioni a livello di compilatore.

Throughput

La larghezza di banda o tasso di produttività complessivo: rappresenta il numero di compiti/task completati dal sistema nell'unità di tempo.
